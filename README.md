## Configuration

1. Clonez ce dépôt :
  ```bash
   git clone -b dev https://github.com/2060485/FitAppMobile.git
  ```
2. Aller dans le frontend :
  ```bash
   cd 420-512
  ```
3. Installer les dépendances :
  ```bash
   npm i
  ```
4. Installer les dépendances :
  ```bash
   npm i
  ```
5. Dans le fichier config.js, mettre l'addresse du backend
6. Démarrer le frontend :
  ```bash
    npx expo start
  ```
7. Se connecter avec un compte expo
8. Aller dans le backend :
  ```bash
    cd BACKEND
  ```
9. Installer les dépendances :
  ```bash
    npm i
  ```
10. Démarrer le backend :
  ```bash
    npm run dev
  ```

## Utilisation

Premièrement, lorsqu'on ouvre l'application, on se retrouve sur une page d'accueil où on peut soit se connecter ou créer un compte. Lorsqu'on est connecté, on est sur la page profil où on peut y voir nos informations. Si on veut en ajouter de nouvelles, on peut aller dans la page option afin de modifier son profil en y ajoutant une image ou une description. Il y a aussi les options pour se déconnecter et pour supprimer son compte. Parmis les autres onglets, il y a la page pedometer qui permet d'enregistrer une nouvelle session de marche sur son compte. Sur son profil, on peut consulter la liste des trajets effectuer. Enfin, dans la section leaderboard, on peut y voir un classement selon le filtre choisi. Si on clique sur un utilisateur, cela ouvrira son profil. Si vous ne voyez pas le leaderboard, reload l'application.
